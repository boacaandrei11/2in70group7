# Rhapsody diagram exports

PNG exports of the Rhapsody diagrams, used in the Overleaf report. The model is the
source; re-export after a model change. Name each file after its diagram:

| File | Diagram (package) |
|---|---|
| `SystemContext.png` | BDD, `Structure::Context` |
| `SmartIntersectionUseCases.png` | use case diagram, `UseCases::UseCaseDiagrams` |
| `RD0_RequirementStructure.png` … `RD7_OperationalDesignDomain.png` | requirement diagrams, `Requirements::SystemRequirements` |

How to export: [tools/requirements/README.md](../../../tools/requirements/README.md#3-requirement-diagrams).
