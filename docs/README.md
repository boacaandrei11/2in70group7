# Documentation

The report is written in Overleaf. This folder keeps what the report and the code
both depend on.

| Folder        | Contents |
|---------------|----------|
| `milestones/` | The PDF exactly as submitted for each milestone (`milestone-1.pdf`, …). Tag the commit `milestone-N`. |
| `diagrams/`   | draw.io sources (`.drawio`) **and** the exported `.png` used in Overleaf. Keep both; name them the same. |
| `decisions/`  | Short decision records: what was decided, why, what it affects. |
