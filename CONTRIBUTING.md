# Working on this repository

Developer notes for Group 7. The project overview is in [README.md](README.md).

## Repository layout

| Folder        | Contents |
|---------------|----------|
| `model/`      | Rhapsody project (`SmartIntersection/SmartIntersection.rpyx` + `SmartIntersection_rpy/`). Source of truth for behaviour. See [model/README.md](model/README.md). |
| `bridge/`     | Hand-written C++ (UDP link, JSON serialisation, command parsing) pulled into the Rhapsody build. |
| `protocol/`   | Message contract between C++ and Python (JSON schemas + conventions). |
| `viz/`        | Python Pygame dashboard (three panels). |
| `scenarios/`  | Scenario definitions (JSON) for repeatable runs. |
| `tools/`      | Dev helpers: requirements source + Rhapsody import, mock simulator, demo launch script, diagram generators. |
| `tests/`      | Verification test cases traced to requirements, and their results. |
| `docs/`       | Submitted milestone PDFs, diagrams (SVG + PNG for Overleaf), decision records. |

The report itself is written in Overleaf and is not stored here.

## Working agreement

- `main` must always open in Rhapsody and build.
- Work on a branch: `model/<topic>`, `feature/<topic>`, `docs/<topic>`, `fix/<topic>`.
- Merge through a pull request reviewed by the other member.
- Before editing a model package, tell the other member which one. Model files cannot
  be merged safely, so only one person edits a given package at a time.
- Submitted milestones are tagged: `milestone-1`, `milestone-2`, …
- Don't commit generated code, build output, virtual environments or videos.

## Getting started

### Rhapsody model
Open `model/SmartIntersection/SmartIntersection.rpyx` in Rhapsody 9.0 (C++). Build instructions:
[model/README.md](model/README.md).

### Requirements
Edit `tools/requirements/requirements.json`, run `python tools/requirements/render.py`
(checks EARS form and regenerates `docs/requirements.md`), then load the change into
Rhapsody with `tools/requirements/rhapsody_import.py`. See
[tools/requirements/README.md](tools/requirements/README.md).

### Dashboard
```bat
cd viz
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m smart_intersection_viz
```

### Without Rhapsody (dashboard development only)
```bat
python tools\mock_sim.py
```

### Diagrams
SVGs in `docs/diagrams/` are shown on the GitHub page; the PNGs next to them are
2× exports for Overleaf. Two diagrams are generated by scripts in `tools/diagrams/`;
the others are hand-written SVG. Re-export PNGs with
`rsvg-convert -z 2 file.svg -o file.png` (or open the SVG in a browser / draw.io).
